# 納付税額確認書（納付税額一覧表）の作り方

決算・確定申告のあと、顧問先へ渡す「納付税額確認書」（年間税額・中間納付額・申告納付額・翌期予定納付額を税目別に並べた表）を作る手順。
申告ソフト（MJS等）が出す様式をfreee会計で運用している顧問先向けに再現したもの。freee会計にはこの形の帳票を出す機能がない（私の知る限り。未確認）。

## 構成

| ファイル | 内容 |
|---|---|
| `make_nozei_kakuninsho.py` | 入力JSONからPDF（A4×2枚）を作る。reportlab + MS明朝が必要（Windows） |
| `example_input.json` | 入力JSONのひな形（架空の数字） |

```
python make_nozei_kakuninsho.py input.json output.pdf
```

出力は1枚目＝納付税額確認書、2枚目＝地方税納付税額明細書（都道府県）。

## 申告書から拾う数字（入力JSON）

| 項目 | 拾う場所 |
|---|---|
| 法人税 年間／中間 | 別表一 差引所得に対する法人税額（13）／中間申告分の法人税額（14） |
| 地方法人税 年間／中間 | 別表一 差引地方法人税額（38）／中間申告分の地方法人税額（39） |
| 法人税割・均等割 | 都道府県 第六号様式の差引法人税割額・均等割額／既に納付の確定した当期分の額 |
| 事業税 所得割・収入割 | 第六号様式 所得割・収入割の税額（既納付額の内訳は前期の翌期予定納付額を使う） |
| 特別法人事業税 | 第六号様式 税額（68）／既納付（71） |
| 消費税・地方消費税 | 第一表 差引税額（9）・譲渡割額の納税額（20）／中間納付税額（10）・中間納付譲渡割額（21） |
| 控除所得税等 | 別表一 控除した金額（19）。無ければ省略 |
| 資本金・当期利益・課税所得 | 別表一の資本金／決算書の当期純利益／別表一（1）の所得金額 |

**申告納付額は申告書の（15）（40）などと一致するはず。納付情報（0004/1004/3004）の金額とも突合すること。**

## 自動計算するもの

- 申告納付額・差引納付額・相殺後納付額 ＝ 年間税額 − 中間納付額
- 翌期予定納付額（法人税・地方法人税・住民税・事業税・特別法人事業税）＝ 年間税額の1/2を100円未満切捨て
- 均等割の翌期予定 ＝ 年間の1/2（年額70,000なら35,000）
- 消費税の翌期予定（1回分）＝ 年間税額×3/12を100円未満切捨て、地方消費税は国税分の1回分×22/78を100円未満切捨て。年額480万円超で年3回
- 消費税の翌期の納期限 ＝ 翌期開始から3か月ごとの期間末の2か月後の月末。土日は翌月曜日に繰り延べ

## 注意

- 翌期予定の計算は前期見本の数字から逆算したルール。**地方法人税だけ前期見本と100円ずれた**（見本の翌期1回分が、ルールで計算した額より100円少なかった）。申告ソフトの数字があればそちらを優先して入力JSONを上書きすること。
- 従業者数・税率（分割基準欄）・「要」の印は未対応。
- 都道府県は1団体分のみ（東京都）。複数団体の場合は明細ページのブロックを増やす必要がある。
- 書類番号は tax-doc-renamer の規則で `0000_納付税額一覧表_YYMM.pdf`。
- 作成日は2026-10-21（オリエンス2026年8月期で初出。数字は `example_input.json` の架空値に差し替え済み）。
