## 運用ルール

- 申告書レビュー・帳簿レビューを行ったら、新しく見つけた落とし穴・法令根拠を該当するチェックリストに追記する（事例名は付録に1行）。順番は帳簿レビュー → 申告書レビュー。
- 条文・区分番号・期間は一次情報で確認してから書く。記憶ベースの追記は禁止。
- 追記したら独立レビュー（別エージェント）で根拠を照合してからコミットする。
- 大きなテーマ（例: 相続・組織再編・国際税務）が増えたら別ファイルに分け、この表に追加する。
